# 酸冷交代浴の主要イベント

2026年11月23日確認。送信先は `G-NX6NQN9RZ1`。既存の専用計測が主要行動をカバーしているため、今回はイベントを追加しません。

| 既存イベント | 発火条件 | 内容 |
|---|---|---|
| quiz_start | 問題数を選んでクイズを開始 | course |
| quiz_answer | クイズで回答を受理 | course、question_number、correct |
| quiz_finish | 結果を表示 | course、answered、correct、completion |
| research_open | 研究・出典の詳細を開く | section_id |

`quiz_finish` の `completion` は `complete` または `partial` です。途中終了と完答を区別し、クリックだけを完了と扱いません。回答内容は送らず、知識クイズの数値集計のみです。症状や個人の健康状態のイベントを新たに追加していません。

実装は `quiz.html` 内の `sanreiAnalytics` とクイズ処理です。施設・商品・共有などの既存イベントはそのまま維持します。今回の作業では自動計測と同義のイベントを重ねていません。

## 送信範囲

計測先はこのサイトの既存GA4ストリームに限定します。新しいGoogleタグやconfigは追加していません。自由入力、検索語、回答本文、氏名、URLのクエリやハッシュを追加イベントのパラメータに含めません。自動page_view・scroll・外部リンク計測と同義のイベントも追加しません。

## 確認方法
